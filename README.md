


Welcome to my personal builder page. This desktop-first web portfolio was built for the **Hack Club Pixl** program.

##  Tech Stack
* **HTML5:** Semantic structure and layout.
* **CSS3:** Flexbox, CSS Grid, and custom interface styling (Pure CSS, no JavaScript).
* **Typography:** [Silkscreen](https://fonts.google.com/specimen/Silkscreen) & [Audiowide](https://fonts.google.com/specimen/Audiowide) via Google Fonts.
